One original haiku about debugging, in the 5-7-5 shape. `main.ts` (Node 22,
standard library only) writes it to `/output/entry.txt`.

```
Breakpoint holds its breath
log line swears no crash happened
the bug wore my face
```

Run it locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
